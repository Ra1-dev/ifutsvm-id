# Licensing and citations

The project software and documentation are distributed under the MIT license
in `LICENSE`. Third-party data and dependencies retain their own terms.

The MATLAB reference repository has no license in the supplied checkout. Its
source code and supplementary PDF are not redistributed. The method citation
and executable differences are in `docs/PORT_DISCREPANCIES.md` and `references.bib`.

KEEL dataset source URLs and checksums are in `data/keel/MANIFEST.json`. The MIT
license does not grant rights over these datasets. Published comparison values
are attributed separately in `results/literature.json` and `references.bib`.

Python and TeX dependencies are installed separately under their own licenses.
Package citation metadata is in `CITATION.cff`.
